Which NFC cards can SmartphoneKey program?

By the SmartphoneKey product team

Published 27 October 2026

Updated 27 October 2026

Product facts checked 27 October 2026

Supported SmartphoneKey reader configurations also let you program MIFARE Classic and MIFARE DESFire EV3 cards. An administrator starts the programming in the Admin Panel, then taps the card on a SmartphoneKey reader that supports programming. Reading a card, programming it, assigning access and using it at a door are separate operations. Confirm other card generations, memory sizes and existing credential formats with us before ordering.

Reading, programming, assigning and using a card

Four separate operations involve a card:

  • Reading: a reader detects the card and its identifier.
  • Programming: a SmartphoneKey reader that supports programming writes a SmartphoneKey credential to a supported card.
  • Assigning access: the Admin Panel links the card to a person and to the doors they may open.
  • Using the card: the person holds the card to a reader at a door they have access to.

A card that a reader can detect is not automatically a card that SmartphoneKey can program.

How an administrator programs a card

  1. In the Admin Panel, choose the site, the person and the doors the card is for.
  2. Choose the card type: MIFARE Classic or MIFARE DESFire EV3.
  3. When the Admin Panel asks, tap the card on the SmartphoneKey reader that supports programming.
  4. Check the result in the Admin Panel before you hand the card over.

The Admin Panel user guide describes each screen.

Which reader programs the card

Cards are programmed with a SmartphoneKey reader that supports programming; SmartphoneKey does not support third-party card programmers. Card programming is available on supported reader configurations, so ask us which configuration to plan for your site.

Why other generations and sizes need confirmation

Cards within one family share a common basis, but chip-level compatibility does not show that SmartphoneKey can program every generation, memory size or credential format. The same applies to other card types and to cards that already carry another system's credentials.

Before ordering, send us the exact card product, its memory size and any credential format already on it. Please do not send keys or card secrets.
