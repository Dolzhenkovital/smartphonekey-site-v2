Which NFC cards can SmartphoneKey program?

By the SmartphoneKey product team

Published 27 October 2026

Product facts checked 26 October 2026

The documented programming workflows name MIFARE Classic and MIFARE DESFire EV3. A compatible programmer or the supported built-in reader programmer writes the credential through the Admin Panel workflow. Confirm the exact card and firmware configuration before ordering. Other generations, memory sizes and third-party credential formats are not covered by the documented workflow.

On this page

  • Reading, programming and assigning access
  • The two documented card families
  • How an operator programs a card
  • Why other generations and sizes need confirmation

Reading, programming and assigning access

Three different things happen to a card, and they are easy to confuse:

  • Reading: a reader detects the card and its identifier.
  • Programming: a supported programming device writes a SmartphoneKey credential to a supported card.
  • Assigning access: the Admin Panel links that credential to a person and to the doors they may open.

A card that a reader can detect is not automatically a card that SmartphoneKey can program.

The two documented card families

Documented card programming workflows
Card familyDocumented workflowCheck before ordering
MIFARE ClassicProgramming through the Admin Panel with a compatible programming device, including the reader's built-in programmer where availableMemory size and any existing credential format
MIFARE DESFire EV3Programming through the Admin Panel with a compatible programming device, including the reader's built-in programmer where availableOther DESFire generations and memory sizes need confirmation

How an operator programs a card

  1. Choose the site, the lock and the person the card is for.
  2. Choose the programming device and the card type.
  3. Tap the card on the programmer.
  4. Check the result in the Admin Panel before handing the card over.

The Admin Panel user guide describes each screen of this workflow.

Why other generations and sizes need confirmation

Cards within one family share a common basis, but chip-level compatibility is not evidence that SmartphoneKey's programming workflow supports every generation, memory size or credential format. The same applies to other card types and to cards already carrying another system's credentials.

Before ordering, send us the exact card product, its memory size and any credential format already on it. Please do not send keys or card secrets.
