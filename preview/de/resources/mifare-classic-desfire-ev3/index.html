Welche NFC-Karten kann SmartphoneKey programmieren?

Vom SmartphoneKey-Produktteam

Ver­öf­fent­licht 27 Oktober 2026

Pro­duk­t­an­ga­ben geprüft 26 Oktober 2026

Die dokumentierten Programmier-Workflows nennen MIFARE Classic und MIFARE DESFire EV3. Ein kompatibles Programmiergerät oder das unterstützte, im Leser integrierte Programmiergerät schreibt die Zutrittsdaten über den Workflow im Admin Panel. Bestätigen Sie vor der Bestellung die genaue Karten- und Firmware-Konfiguration. Andere Generationen, Speichergrößen und Zutrittsdatenformate von Drittanbietern sind durch den dokumentierten Workflow nicht abgedeckt.

Lesen, Pro­gram­mie­ren und Zuweisen von Zutritt

Mit einer Karte geschehen drei ver­schie­dene Dinge, die leicht zu verwechseln sind:

  • Lesen: Ein Leser erkennt die Karte und ihre Kennung.
  • Pro­gram­mie­ren: Ein unter­stütz­tes Pro­gram­mier­ge­rät schreibt SmartphoneKey-Zutritts­da­ten auf eine unter­stützte Karte.
  • Zutritt zuweisen: Das Admin Panel verknüpft diese Zutritts­da­ten mit einer Person und mit den Türen, die sie öffnen darf.

Eine Karte, die ein Leser erkennen kann, ist nicht automatisch eine Karte, die SmartphoneKey pro­gram­mie­ren kann.

Wie ein Bediener eine Karte pro­gram­miert

  1. Wählen Sie den Standort, das Schloss und die Person, für die die Karte bestimmt ist.
  2. Wählen Sie das Pro­gram­mier­ge­rät und den Kartentyp.
  3. Halten Sie die Karte an das Pro­gram­mier­ge­rät.
  4. Prüfen Sie das Ergebnis im Admin Panel, bevor Sie die Karte übergeben.

Das Benutzerhandbuch für das Admin Panel beschreibt jeden Bildschirm dieses Workflows.

Warum andere Gene­ra­ti­o­nen und Größen bestätigt werden müssen

Karten einer Familie haben eine gemeinsame Basis, aber Kom­pa­ti­bi­li­tät auf Chipebene ist kein Nachweis dafür, dass der Programmier-Workflow von SmartphoneKey jede Generation, jede Spei­cher­größe oder jedes Zutritts­da­ten­for­mat unterstützt. Dasselbe gilt für andere Kartentypen und für Karten, auf denen sich bereits Zutritts­da­ten eines anderen Systems befinden.

Senden Sie uns vor der Bestellung das genaue Kar­ten­pro­dukt, seine Spei­cher­größe und jedes bereits darauf vorhandene Zutritts­da­ten­for­mat. Bitte senden Sie keine Schlüssel oder Kar­ten­ge­heim­nisse.
