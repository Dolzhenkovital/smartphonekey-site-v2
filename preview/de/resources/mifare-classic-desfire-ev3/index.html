Welche NFC-Karten kann SmartphoneKey programmieren?

Vom SmartphoneKey-Produktteam

Veröffentlicht 27. Oktober 2026

Aktualisiert 27. Oktober 2026

Produktangaben geprüft 27. Oktober 2026

Mit unterstützten SmartphoneKey-Leserkonfigurationen können Sie außerdem Karten vom Typ MIFARE Classic und MIFARE DESFire EV3 programmieren. Ein Administrator startet die Programmierung im Admin Panel und hält die Karte dann an einen SmartphoneKey-Leser, der das Programmieren unterstützt. Das Lesen einer Karte, das Programmieren, das Zuweisen von Zutritt und das Verwenden an der Tür sind getrennte Vorgänge. Klären Sie andere Kartengenerationen, Speichergrößen und vorhandene Zutrittsdatenformate vor der Bestellung mit uns.

Lesen, Programmieren, Zuweisen und Verwenden einer Karte

An einer Karte sind vier getrennte Vorgänge beteiligt:

  • Lesen: Ein Leser erkennt die Karte und ihre Kennung.
  • Programmieren: Ein SmartphoneKey-Leser, der das Programmieren unterstützt, schreibt SmartphoneKey-Zutrittsdaten auf eine unterstützte Karte.
  • Zutritt zuweisen: Das Admin Panel verknüpft die Karte mit einer Person und den Türen, die sie öffnen darf.
  • Karte verwenden: Die Person hält die Karte an einen Leser an einer Tür, zu der sie Zutritt hat.

Eine Karte, die ein Leser erkennen kann, ist nicht automatisch eine Karte, die SmartphoneKey programmieren kann.

Die beiden dokumentierten Kartenfamilien

Karten, die SmartphoneKey programmieren kann
KartenfamilieSo wird programmiertVor der Bestellung prüfen
MIFARE ClassicÜber das Admin Panel, an einem SmartphoneKey-Leser, der das Programmieren unterstütztSpeichergröße und ein eventuell bereits auf der Karte vorhandenes Zutrittsdatenformat
MIFARE DESFire EV3Über das Admin Panel, an einem SmartphoneKey-Leser, der das Programmieren unterstütztAndere DESFire-Generationen und Speichergrößen müssen bestätigt werden

So programmiert ein Administrator eine Karte

  1. Wählen Sie im Admin Panel den Standort, die Person und die Türen, für die die Karte gedacht ist.
  2. Wählen Sie den Kartentyp: MIFARE Classic oder MIFARE DESFire EV3.
  3. Halten Sie die Karte an den SmartphoneKey-Leser, der das Programmieren unterstützt, wenn das Admin Panel dazu auffordert.
  4. Prüfen Sie das Ergebnis im Admin Panel, bevor Sie die Karte übergeben.

Die Anleitung für das Admin Panel beschreibt jede Ansicht.

Welcher Leser programmiert die Karte?

Karten werden mit einem SmartphoneKey-Leser programmiert, der das Programmieren unterstützt; SmartphoneKey unterstützt keine Geräte von Drittanbietern zum Programmieren von Karten. Die Kar­ten­pro­gram­mie­rung ist bei unterstützten Leser­kon­fi­gu­ra­ti­o­nen verfügbar. Fragen Sie uns daher, welche Konfiguration Sie für Ihren Standort einplanen sollten.

Warum andere Generationen und Größen bestätigt werden müssen

Karten einer Familie haben eine gemeinsame Grundlage, doch Kompatibilität auf Chipebene zeigt nicht, dass SmartphoneKey jede Generation, Speichergröße oder jedes Zutritts­da­ten­for­mat programmieren kann. Dasselbe gilt für andere Kartentypen und für Karten, die bereits Zutrittsdaten eines anderen Systems tragen.

Senden Sie uns vor der Bestellung das genaue Kartenprodukt, seine Speichergröße und ein eventuell schon darauf vorhandenes Zutritts­da­ten­for­mat. Bitte senden Sie keine Schlüssel und keine geheimen Kartendaten.
