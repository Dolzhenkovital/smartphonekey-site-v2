Machen Sie aus vernetzten Geräten praktische Workflows.

Nutzen Sie den Scenario Builder, um unter­stützte Auslöser, Bedingungen und Aktionen zu kombinieren. Beginnen Sie mit einer einfachen Regel oder erstellen Sie einen detail­lier­te­ren Workflow aus den Funktionen, die Ihre Geräte melden.

Vier Beispiele.

Jedes davon ist ein Beispiel dafür, was unter­stützte Geräte gemeinsam leisten können, kein Versprechen für jedes Gerät.

Bei­spiel­s­ze­na­rien
BeispielWennNur wennDann
Eingang beleuchtenEin kompatibler Kon­takt­sen­sor meldet eine offene TürWährend eines kon­fi­gu­rier­ten Abend­zeit­plansUnter­stützte Leuchte einschalten
Auf eine Leckage reagierenEin kompatibler Lecka­ge­s­en­sor meldet WasserImmerSenden Sie einen Schließ­be­fehl an ein unter­stütz­tes Was­ser­ven­til. Bestätigen Sie die Gerä­teant­wort und behalten Sie die manuelle Steuerung bei.
Raum anpassenEin unter­stütz­ter Tem­pe­ra­tur­sen­sor erreicht einen gewählten Schwel­len­wertImmerSollwert eines kompatiblen Thermostats ändern
Arbeitstag abschließenEin ZeitplanUnter­stützte Bedingungen Ihrer WahlAusgewählte Leuchten oder Steckdosen schalten. Halten Sie unver­zicht­bare Geräte aus dieser Regel heraus.

Prüfen Sie die Funktionen hinter dem Beispiel.

Eine Matter-Kenn­zeich­nung bedeutet nicht, dass jedes Gerät dieselben Befehle bereit­stellt. Szenarien hängen von den in Betrieb genommenen Geräten, ihren gemeldeten Funktionen und ihrer Firmware ab. In der aktuellen Imple­men­tie­rung gehört jedes Szenario zu einem Hub.

Kompatible Gerä­te­funk­ti­o­nen ansehen

Sehen Sie, was übernommen wurde.

Der Ver­wal­tungs­work­flow unter­schei­det Änderungen, die auf den Hub warten, von Änderungen, die der Hub übernommen oder abgelehnt hat. Das Bearbeiten eines Szenarios ersetzt nicht automatisch die Version, die bereits auf dem Hub läuft.

Fragen

Funk­tio­niert SmartphoneKey mit jedem Matter-Gerät?

Die Kom­pa­ti­bi­li­tät hängt vom Gerätetyp, den bereit­ge­stell­ten Funktionen, der Firmware und der Kon­fi­gu­ra­tion ab. Prüfen Sie die Funktionen, die Ihr Workflow erfordert, statt anzunehmen, dass jedes Matter-Gerät sie unterstützt.
