Was ein Szenario nutzen kann

Ein Matter-Kennzeichen sagt nicht, dass jedes Gerät dieselben Funktionen bietet. Ein Szenario kann nur nutzen, was jedes in Betrieb genommene Gerät meldet und seine Firmware unterstützt. Jedes Szenario läuft auf einem Hub mit den Geräten, die an ihm in Betrieb genommen wurden.

Unterstützte Gerätefunktionen ansehen

Prüfen, ob der Hub die Änderung übernommen hat

Das Admin Panel zeigt, ob eine Sze­na­rio­än­de­rung auf den Hub wartet, übernommen oder abgelehnt wurde. Bis der Hub eine Bearbeitung übernimmt, läuft weiterhin die Version, die bereits auf dem Hub ist.

Fragen

Funktioniert SmartphoneKey mit jedem Matter-Gerät?

Das hängt vom Gerätetyp, den gemeldeten Funktionen, der Firmware und Ihrer Konfiguration ab. Prüfen Sie die Funktionen, die Ihr Szenario braucht, statt davon auszugehen, dass jedes Matter-Gerät sie bietet.

Kann ein Szenario Geräte an zwei Hubs nutzen?

Nein. Jedes Szenario gehört derzeit zu einem Hub und den Geräten, die an ihm in Betrieb genommen wurden. Planen Sie jedes Szenario um den Hub herum, der die benötigten Geräte steuert.
