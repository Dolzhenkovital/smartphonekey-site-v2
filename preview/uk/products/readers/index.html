Зчитувач і контролер доступу в одному пристрої

Зчитувачі SmartphoneKey читають NFC-картки та цифрові ключі, а контролер доступу вбудовано в сам пристрій. Обирайте версію LTE або Wi-Fi залежно від зв’язку біля кожних дверей.

Порівняти LTE і Wi-Fi Інструкція з монтажу та підключення

Що робить зчитувач

Зчитувач читає NFC-картки та ключі у Wallet і містить контролер доступу для дверей. Він підключається до SmartphoneKey через LTE або Wi-Fi, щоб отримувати зміни й надсилати події.

Що ще потрібно для монтажу

  • Живлення біля кожних дверей
  • Сумісний замок і, за потреби, пристрої для виходу
  • Проводка за інструкцією з монтажу та підключення
  • Надійний зв’язок LTE або Wi-Fi у місці встановлення зчитувача

LTE чи Wi-Fi

Обидві версії керуються через Admin Panel, мають вбудований контролер доступу, можуть працювати як Thread Border Router і маршрутизатор mesh-мережі та потребують живлення, сумісного замка й проводки. Відрізняється лише зв’язок:

Запитайте нас, яка версія підходить для вашого регіону. Зв’язок обирають окремо для кожних дверей.

Кожен зчитувач — маршрутизатор Thread і Border Router

Кожен зчитувач SmartphoneKey може працювати як Thread Border Router і як маршрутизатор у mesh-мережі Thread. Для жодної з цих ролей не потрібна окрема версія мікропрограми, тож зчитувачі на об’єкті можуть утворити одну mesh-мережу та з’єднати її з вашою IP-мережею.

Водночас покриття mesh-мережі та маршрут до інтернету залежать від розміщення, живлення та будівлі. Функції контролера Matter підтверджують для кожного проєкту.

Покриття залежить від будівлі, розміщення та радіоумов. Ми допомагаємо спланувати мережу для вашого об’єкта.

Запитання

Чим відрізняються LTE- і Wi-Fi-зчитувачі?

Вони по-різному підключаються. LTE-зчитувач працює через мобільну мережу й потребує SIM-картки та послуги зв’язку; Wi-Fi-зчитувач працює через Wi-Fi об’єкта й потребує надійного покриття та налаштувань мережі. Перевірте зв’язок біля кожних дверей.

Чи може один зчитувач забезпечувати зв’язок для інших зчитувачів?

Так. Кожен зчитувач може працювати як маршрутизатор Thread і як Border Router, тож зчитувачі можуть спільно використовувати mesh-мережу Thread і виходити в інтернет через зчитувач, який має підключення. Скільки зчитувачів ділять це підключення і що буде, якщо воно зникне, залежить від системи; топологію ми плануємо разом з вами. Це не означає автоматичного перемикання на резерв.

На якій відстані один від одного можна встановлювати зчитувачі?

Покриття залежить від будівлі, перешкод, розміщення та конфігурації обладнання. Плануйте й перевіряйте покриття на місці: єдиної відстані для всіх об’єктів немає.

Чи можна залишити наявні замки або камери?

Спершу перевірте точну модель замка, його електричний інтерфейс і моделі камер. Перш ніж планувати повторне використання наявного обладнання, надішліть нам дані про моделі.
